# Dashboard Mockup Reference

Referencia visual para el dashboard principal de Doyess Film.

Fuente visual: mockup compartido por el usuario en esta conversación. Esta referencia queda como norte visual del dashboard hasta que se implementen los datos reales.

## Qué comunica esta referencia

- Interfaz cinematográfica premium, oscura y editorial.
- Navegación lateral limpia con estado activo en rojo cereza.
- Hero de bienvenida grande y protagonista.
- Buscador superior discreto y funcional.
- Métricas grandes con micrográficas y acentos rojos.
- Tarjeta de recomendación destacada con póster real y acciones rápidas.
- Paneles secundarios con actividad reciente, géneros favoritos y tendencias.
- Fondo con profundidad visual y posters difuminados para atmósfera de cine.

## Dirección que debe seguir el dashboard

- Color base: negro profundo.
- Acento: rojo cereza.
- Texto principal: blanco roto.
- Jerarquía fuerte, con números grandes y títulos editoriales.
- Evitar grids genéricos de tarjetas iguales.
- Usar pósters TMDB y bloques asimétricos.

## Pautas de implementación

- La cabecera debe incluir logo, buscador y acciones de usuario.
- El sidebar debe priorizar secciones: Inicio, Para vos, Laboratorio, Mi biblioteca y Analista IA.
- La tarjeta central debe parecer una recomendación viva, no un widget estático.
- Las métricas deben leerse rápido y sentirse parte de una composición editorial.
- El sistema debe soportar estados reales, vacíos y de carga sin inventar datos.

## Objetivo visual

Que el dashboard se sienta como un centro de control cinéfilo, elegante y listo para evolucionar hacia datos reales de IMDb y TMDB.
