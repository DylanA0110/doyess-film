# Home Mockup Reference

Referencia visual de la landing principal de Doyess Film.

Fuente visual: mockup compartido por el usuario en esta conversación. Esta referencia define la dirección del inicio hasta que la interfaz se consolide con datos reales.

## Qué debe conservar la home

- Fondo oscuro profundo con atmósfera cinematográfica.
- Logo rojo a la izquierda con el nombre de marca visible.
- Navegación superior limpia y breve.
- Título hero grande, editorial y centrado en la propuesta de valor.
- Texto descriptivo corto sobre IMDb, gustos y algoritmo.
- CTA principal rojo para comenzar con Google.
- Previsualización del dashboard a la derecha como pieza protagonista.
- Métricas grandes, recomendación destacada, géneros y actividad visual.
- Sensación de monitor de cine / sala premium.

## Qué evitar en el inicio

- Secciones largas debajo del hero.
- Anclas o navegación interna innecesaria como `#inicio`.
- Demasiadas tarjetas repetidas.
- Bloques demasiado técnicos o con lenguaje genérico de dashboard.
- Botones o elementos que desvíen la atención del visual principal.

## Objetivo de implementación

La home debe leerse como una portada cinematográfica interactiva, no como una página de administración. La prioridad es el impacto visual, la claridad del mensaje y la relación entre hero y preview.
