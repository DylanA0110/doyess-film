# Propuesta de valor (UVP)

**Doyess Film** = data storytelling cinematográfico personal: importas tu IMDb, obtienes estadísticas y recomendaciones **explicables** (Bayes, Z-score, coseno), en una UI oscura tipo cartelera — sin feed social ni stats de pago.

## Diferenciación breve

| Producto | Hueco que cubre Doyess |
|----------|-------------------------|
| Letterboxd | FYP predictivo personal + matemática visible |
| Criticker | Misma rigurosidad con UX moderna |
| Trakt | Minimalismo: “¿qué veo hoy?” |
| MovieLens / Taste | Caja negra → “ADN” de cada recomendación |

## Pilares

1. Íntimo (solo tus datos)
2. Matemática legible
3. Premium cinematográfico
4. Una acción clara (película del día → Explorar)

Ver [`recommendation-engine.md`](./recommendation-engine.md) para el detalle técnico.
